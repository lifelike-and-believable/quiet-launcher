# Recover after an update or reset

<!-- docs/product/stories/setup/recover.md. Release: first. -->

As the set-up person, I want running the setup procedure again to bring the quiet home screen back
after a Google TV update or reset has undone it, so that recovering is the same steps I already
know.

## Acceptance criteria

- If Google TV's home screen has come back after a system update or a reset, running the written
  setup procedure again makes the quiet home screen the home screen again.
- Running it on a TV where the product is already set up does no harm and changes nothing the
  household would notice.
