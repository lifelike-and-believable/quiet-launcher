# New apps appear, removed apps disappear

<!-- docs/product/stories/quiet-home/new-and-removed-apps.md. Release: first. -->

As the set-up person, I want an app I install to show up on its own and one I uninstall to go away,
so that I never have to update the home screen by hand.

## Acceptance criteria

- After an app is installed, it appears at the end of the list on the quiet home screen, without
  anyone doing anything else.
- After an app is uninstalled, it is no longer on the quiet home screen.
- Neither changes the order of the other apps.
