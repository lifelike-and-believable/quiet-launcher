# The TV's settings from the home screen

<!-- docs/product/stories/quiet-home/tv-settings.md. Release: first. -->

As a household viewer, I want to reach the TV's own settings from the home screen, so that I can,
for example, check the Wi-Fi without calling the project lead over.

## Acceptance criteria

- The quiet home screen has a settings item, reached with the direction pad.
- Selecting it opens the TV's own settings (network, display, accounts, and so on).
- Pressing Back or Home from the settings returns to the quiet home screen.
