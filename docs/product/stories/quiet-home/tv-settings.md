# The TV's settings from the home screen

<!-- docs/product/stories/quiet-home/tv-settings.md. Release: first. -->

As the set-up person, I want the TV's settings reachable from the quiet home screen with the remote,
so that I can change a setting without going to the PC or undoing anything.

## Acceptance criteria

- The quiet home screen has a settings item, reached with the direction pad.
- Selecting it opens the TV's settings, the same ones Google TV's settings icon opens (network,
  display, accounts, and so on).
- Pressing Home from anywhere in the settings returns to the quiet home screen.
