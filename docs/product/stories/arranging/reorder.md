# Put the apps in the household's order

<!-- docs/product/stories/arranging/reorder.md. Release: second (epic-arranging). REQ-home-3. -->

As the set-up person, I want to put the household's apps in the order we use them, so that the
apps everyone reaches for come first and stay there.

## Acceptance criteria

- In arrange mode, I can pick up any app, move it to any place in the list with the direction pad,
  and put it down there.
- While I am moving an app, Back puts it back where it was.
- The new order is on the quiet home screen as soon as I leave arrange mode, the same for everyone,
  whichever Google TV profile is in use.
- The order is the same after the TV restarts and after a system update.
- A newly installed app appears at the end of the list; removing an app does not change the order
  of the others.
